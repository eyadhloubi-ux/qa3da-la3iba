# قعدة لعّيبة 🎪

12 لعبة صغيرة بتنلعب من الموبايلات بنفس القعدة: فردي أو فرق، مع عجلة حظ ورهان وحفلة كشف وصورة ستوري.
من ألعاب «قعدة رواق» ضمن مشروع «صار بدها قعدة» — إعداد م. إياد حلوبي.

## الألعاب
🎈 نفّخ البالونة · 🕯️ طفّي الشمع · 🔮 المتاهة · ⏱️ 10 ثواني بالضبط · 🤠 مبارزة الكاوبوي · 🪰 اصطاد الدبّانة
👆 الطابع الأسرع · ⭕ الدائرة الكاملة · 🎨 الألوان الكذابة · 🧠 احفظ الترتيب · 🔢 عدّ النقاط · 🔍 مين الغريب

ألعاب المايك (البالونة والشمع): قبل البداية في معاينة نفخ بـ3 طرق كشف، اللعبة بتختار لحالها الطريقة اللي بتشتغل عالموبايل، واللاعب بيقدر يبدّل الطريقة أو يلعب باللمس. المتاهة بتطلب إذن حساس الحركة، وإذا ما انعطى بيشتغل بديل باللمس.

## الرفع على GitHub
1. افتح github.com واعمل مستودع جديد (Repository) باسم `qa3da-la3iba`.
2. اكبس «uploading an existing file» واسحب **كل الملفات اللي جوّا هالمجلد** (مو المجلد نفسو).
3. اكبس «Commit changes».

## النشر على Render
1. افتح render.com وسجّل دخول بحساب GitHub.
2. اكبس **New +** ← **Blueprint**، واختار المستودع `qa3da-la3iba`.
3. Render رح يقرأ ملف `render.yaml` لحالو. اكبس **Apply**.
4. بعد دقيقتين بيطلعلك رابط متل `https://qa3da-la3iba.onrender.com` — هاد رابط اللعبة.

> بالخطة المجانية Render بينيّم السيرفر إذا ما حدا زارو 15 دقيقة. السيرفر بيزور حالو كل 10 دقايق لحتى يضل صاحي (بتوقّفها بمتغيّر `KEEP_AWAKE=off`). الخطة المجانية فيها 750 ساعة بالشهر، وهي بتكفي خدمة وحدة شغّالة طول الشهر.

## الإحصائيات
- الرابط: `https://رابط-اللعبة/stats?key=المفتاح`
- المفتاح موجود بـ Render ← الخدمة ← **Environment** ← `STATS_KEY` (بينولد لحالو، وفيك تغيّرو).
- الأرقام بتنحفظ بملف. إذا بدك تضل محفوظة بعد كل إعادة نشر، اعمل قاعدة Postgres مجانية على Render وحط رابطها بمتغيّر اسمو `DATABASE_URL`.

## صفحة الإدارة (إلك انت بس)
- الرابط: `https://رابط-اللعبة/admin?key=المفتاح` (نفس مفتاح الإحصائيات `STATS_KEY`، أو حط مفتاح خاص بمتغيّر `ADMIN_KEY`).
- منها بتفعّل أو بتوقّف أي لعبة. اللعبة الموقوفة بتبين للناس مقفلة «🔒 قريباً» وما بتدخل العجلة. منيحة لتفتح الألعاب لعبة لعبة كل أسبوع.

## روابط مفيدة
- `?r=ABCDE` ← فوتة مباشرة على قعدة بكودها (هيك بيشتغل الـQR).
- الريس بيقدر يطلّع أي لاعب بأي وقت من زر 👥 فوق، حتى لو اللاعب طلع لحالو (بيبين «مو موصول»).
- ترتيب الألعاب دايماً بعجلة الحظ، والريس هو اللي بيكبس «دوّر العجلة» فبتدور عند الكل بنفس اللحظة.
- المجموع ما بيبين بعد كل جولة، بيبين بآخر القعدة بس، إلا إذا الريس كبس «📊 اعرض المجموع للكل».
- إذا الريس سكّر الجولة، اللي لسّا عم يلعب بتنحسبلو نتيجتو لهديك اللحظة.
- الفرق: قائد الفريق 👑 بيغيّر اسم فريقه، والريس بيقدر يقفّل الفرق لحتى ما حدا يبدّل.
- حفلة الكشف بتمشي من المركز الأخير للأول، مع طبلة وأصوات، والعجلة إلها صوت تكتكة وهي عم تدور.
- زر 🏠 فوق بكل شاشة: قعدة جديدة بنفس الناس أو بناس جداد، أو تطلع وترجع عالبداية.
- بآخر القعدة الريس بيختار: قعدة جديدة «بنفس الناس» (الكل بيضل جوّا) أو «بناس جداد» (كود جديد والكل بيفوت من أول).

## التشغيل على جهازك (اختياري)
```
npm install
npm start
```
وافتح `http://localhost:3000`.

| `public/engine.js` | منطق اللعبة: الأوضاع، الفرق، الرهان، النقاط |
| `public/games.js` | الـ12 لعبة الصغيرة |
| `public/app.js` | الواجهة والاتصال |
| `public/story.js` | صورة الستوري (3 أشكال × فاتح/داكن) |
| `render.yaml` | إعدادات النشر على Render |
